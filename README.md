# فاکتور فروش ۲

فاکتور فارسی برای شیلان ستور گستر، با طراحی سیاه‌وسفید، پیش‌نمایش زنده و خروجی A4.

[باز کردن برنامه](https://qaradagh.github.io/Sales-invoice-2/)

این مخزن مستقل از [نسخهٔ اول](https://github.com/qaradagh/Sales-invoice) است.
تغییرهای نسخهٔ ۲ روی کد یا داده‌های کاربران نسخهٔ اول اعمال نمی‌شوند.

## محیط کار

- **فایل:** فاکتور جدید، باز کردن فایل، ذخیرهٔ فایل قابل ویرایش و آرشیو فاکتورها.
- **خروجی:** دانلود PDF، دانلود تصویر PNG و چاپ.
- **اطلاعات اصلی:** شماره، تاریخ شمسی، واحد پول و مشخصات خریدار.
- **اقلام و مبالغ:** شرح کالا، وزن، قیمت هر کیلو، تخفیف، مالیات، حمل، مانده و پرداختی.
- **تنظیمات:** فروشنده، اطلاعات بانکی، توضیحات، مهر و امضا، حالت روشن/تیره و نصب برنامه.
- در موبایل، دو نمای «ویرایش فاکتور» و «پیش‌نمایش» در دسترس است.

رابط و برگه از طرحی با عنوان بزرگ، خطوط ظریف، سربرگ روشن و جدول تیره الهام گرفته‌اند.
بخش‌های امضا روشن هستند تا روی نسخهٔ چاپی هم بتوان مهر زد و امضا کرد.

## ذخیره‌سازی و انتقال

اطلاعات به‌صورت خودکار در همین مرورگر ذخیره می‌شوند. با دریافت PDF/PNG یا چاپ،
فاکتور به آرشیو هم افزوده می‌شود. فایل قابل ویرایش را از «فایل ← ذخیره فایل» دریافت کنید.

نام‌های ذخیره‌سازی پیش‌نویس، آرشیو، مخاطبان، ترجیحات، اتصال پوشه و هویت برنامهٔ نصب‌شده
برای نسخهٔ ۲ جداست. پاک‌سازی کش فقط کش همین نسخه و همین مسیر را هدف می‌گیرد.
برای انتقال اختیاری فاکتور قدیمی، فایل JSON نسخهٔ اول را از «فایل ← باز کردن فایل» وارد کنید.
برای آرشیو پوشه‌ای نسخهٔ ۲، پوشه‌ای جدا انتخاب کنید تا فایل‌های هم‌شمارهٔ نسخهٔ اول جایگزین نشوند.
انتخاب پوشه به پشتیبانی مرورگر از File System Access API بستگی دارد.

## نصب و کارکرد آفلاین

راهنمای نصب در تب تنظیمات قرار دارد. پس از اولین بارگذاری کامل، فایل‌های برنامه،
قلم‌ها و لوگو برای کارکرد آفلاین ذخیره می‌شوند. در آیفون/آی‌پد، از گزینهٔ
Add to Home Screen در منوی اشتراک‌گذاری سافاری استفاده کنید.

خود فاکتور و رنگ خروجی مستقل از حالت روشن یا تیرهٔ محیط کار هستند.
برای چاپ مرورگر، نمایش پس‌زمینه‌ها را فعال کنید؛ PDF خروجی رنگ‌های طرح را در خود دارد.

## توسعه و بررسی

پروژه با HTML، CSS و JavaScript ساده ساخته شده و وابستگی زمان اجرا ندارد.

```sh
python -m http.server 8000
node --test tests/isolation.test.cjs
```

سپس `http://localhost:8000` را باز کنید. آزمون‌ها جداسازی داده‌ها و حفظ کش نسخهٔ اول
و سایر برنامه‌ها را بررسی می‌کنند. برای انتشار، شاخهٔ `main` و مسیر `/` در GitHub Pages تنظیم شده است.
پس از تغییر فایل‌های برنامه، مقدار `VERSION` در `sw.js` را افزایش دهید تا کش نصب‌شده به‌روز شود.

فایل‌های اصلی: `index.html`، `assets/css/app.css`، `assets/js/app.js` (محاسبات و وضعیت)،
`assets/js/ui.js` (منوها و تب‌ها)، `assets/js/export.js` (PDF/PNG) و `assets/js/pwa.js` (نصب).

قلم وزیرمتن اثر صابر راستی‌کردار تحت پروانهٔ SIL Open Font License است؛
متن پروانه در `assets/fonts/LICENSE.txt` قرار دارد.
